# DureBot 다운로드

DureBot의 공개 설치 파일과 업데이트 메타데이터를 제공하는 저장소입니다.
앱 소스 코드는 이 저장소에 업로드하지 않습니다.

[최신 릴리스와 다운로드](https://github.com/Pixel-Tao/durebot-releases/releases/latest)에서
운영체제에 맞는 설치 파일을 받으세요. 첫 공개 릴리스 전에는 다운로드가 제공되지 않습니다.

- Windows: `DureBot-setup.exe`를 실행해 설치합니다. 설치된 앱은 새 버전을 확인합니다.
- Mac (Apple Silicon): `DureBot.dmg`를 열고 앱을 응용 프로그램으로 옮깁니다.
  현재 앱은 서명·공증되지 않았습니다. Mac 업데이트는 새 버전 알림과 다운로드 링크만 제공하며,
  사용자가 직접 설치합니다.
- 무결성 확인: 릴리스에 첨부된 `SHA256SUMS-windows-x64.txt` 또는
  `SHA256SUMS-macos-arm64.txt`와 다운로드한 파일의 SHA-256을 비교하세요.

릴리스는 검토 후 수동으로 게시합니다. 초안 릴리스는 일반 사용자에게 보이지 않습니다.
